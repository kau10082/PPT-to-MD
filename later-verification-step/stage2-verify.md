# ppt-to-md 第二階段（B）：圖片出處核實與坐實帳

> 輸入：第一階段產出的 markdown（已含「圖片出處候選（deck 自標）」區塊與降級保留的原圖）。
> 目的：用 PubMed / Consensus MCP 核實圖的出處與重點，**以查證過的文字取代不可靠的像素**，
> 但取代物必須誠實標明「坐實到什麼程度、證據等級為何」。
> 這是「有界核實」，不是自動生成。預設關閉，需明確開啟。**絕不讀像素猜數字。**

---

## 一、圖號粒度決策樹（回答「能不能標到 fig 1 / fig 2」）

對每一張圖，依序判斷，**停在第一個成立的層級，不得往下猜**：

1. **deck 自標圖號** → 粒度＝`圖號(deck明標)`。這是抽取，最可靠，直接採用。
2. **deck 只標論文，且該文有 PMC 全文** → 可嘗試 `圖號(全文推斷)`：
   抓全文各 figure caption，拿投影片圖的內容（軸標題／數列／數值）去比對。
   - 僅在比對**唯一且明確**時採用，並「必須」附上比對理由。
   - 論文有多張相似圖、或投影片疑似重繪/合併數據 → 不得推斷，降為論文層。
3. **deck 只標論文，且無 PMC 全文**（或查無全文） → 粒度＝`論文層(圖號不可考)`。
   **停在論文層，明白標「圖號不可考（無開放全文）」。硬猜 fig 幾＝confabulation，禁止。**
4. **deck 完全未標出處** → 粒度＝`出處不明`。不得替它指派任何來源。

> 實測經驗：藥廠簡報的圖多為情境 3（引用文獻無開放全文，圖號不可考），
> 少數備註會明標情境 1 的「(Figure 1)」。情境 2 需個案判斷，寧缺勿猜。

---

## 二、工具工作流（逐圖）

1. `PubMed:lookup_article_by_citation` — 用 deck 標的作者/年/期刊/頁碼取 PMID，**確認文獻真實存在**。
2. `PubMed:get_article_metadata` — 取摘要與 DOI。從摘要抓可對照的 headline 數值。
3. `PubMed:convert_article_ids`（PMID→PMCID）— 判斷有無開放全文（決定能否走情境 2）。
4. 若有 PMCID：`PubMed:get_full_text_article` — 取 figure caption，供圖號推斷與補齊資料點。
5. `Consensus:search` — 「提及重點」的橫向查證：此宣稱在整體文獻是否被廣泛支持
   （非只此一篇說了算）。用於在坐實帳標註「文獻共識」。
6. 全程附 PubMed 出處與 DOI 連結（PubMed 使用規範）。

## 三、坐實帳輸出格式（🔒 鎖定 schema，不得逐次漂移）

每一張要核實的圖，輸出「一個」如下區塊。欄位、順序、狀態符號固定：

```
### 圖片核實｜投影片 {N}｜{圖的簡短描述}
- deck 自標出處（逐字）：{原文，如 "Adapted from Nordqvist et al, 2014"}
- 對應文獻：{PMID} ｜ {DOI 連結} ｜ 存在確認：{✅/❌}   〔據 PubMed〕
- 出處粒度：{圖號(deck明標) / 圖號(全文推斷) / 論文層(圖號不可考) / 出處不明}
  └ 若為全文推斷：比對理由：{……}
- 坐實帳（逐資料點；不得替合併/缺項填值）：
  | 圖中資料點 | 投影片宣稱 | 來源坐實值 | 狀態 |
  | --- | --- | --- | --- |
  | {點1} | {宣稱} | {來源值或「僅稱方向一致，無數值」或「—」} | {✅/🟡/⚪/🔴} |
- 證據等級：{RCT / 前瞻性 / 回顧性觀察登錄 / 網絡統合 / 機轉推論 …}（照原研究設計，不得升級）
- 文獻共識（Consensus）：{此宣稱是否被整體文獻支持的一句話總結}
- 原圖（降級保留，供人工複核）：{figures/slideN.png 連結，或「未 rasterize」}
- 總結旗標：{🟢完全坐實 / 🟡部分坐實 / ⚪待全文或查無 / 🔴矛盾 / ⚫出處不明}
```

### 狀態符號（四態 + 出處態，固定語意）

| 符號 | 語意 | 觸發條件 |
| --- | --- | --- |
| ✅ | 一致坐實 | 來源有明確數值，且與投影片宣稱相符 |
| 🟡 | 部分坐實 | 來源僅稱方向/顯著性一致，但無該資料點的具體數值 |
| ⚪ | 待全文／查無 | 數值僅在全文圖表、此工具鏈取不到；或整篇查無 |
| 🔴 | **矛盾** | 來源數值與投影片宣稱對不上 → **最高優先，必須醒目標出** |
| ⚫ | 出處不明 | deck 未標來源，無從核實 |

> 🔴 矛盾是本流程最重要的產物：它代表投影片可能改圖、引錯、或過度詮釋。
> 一旦出現，於文件開頭「核實摘要」置頂列出，不得埋在內文。

---

## 四、以坐實帳取代圖片的規則

- 取代文字＝坐實帳本身，**不是**一段通順的改寫。缺的資料點就顯示 ⚪/🟡，不用「顯著降低」含混填滿。
- **證據等級必須隨數字一起搬。**「降低 26%」出自回顧性登錄研究 ≠ 出自 RCT；
  取代文字若省略設計標籤，等於偷偷升級證據強度，禁止。
- **原圖降級保留、不砍。** 既然取代可能不完整，rasterize 的 PNG 一律連結於區塊末，供人工複核。
- 任何「來源坐實值」都必須可回溯到 PubMed/Consensus 的具體回傳，不得憑印象填寫。

---

## 五、人工核對（human holdout，不可省）

- 🔴 矛盾項：逐一回原圖與原文確認，是投影片錯、還是核實比對錯。
- `圖號(全文推斷)` 項：確認比對理由是否真的唯一，排除「多張相似圖」誤配。
- 證據等級標註：確認沒有把觀察性研究讀成因果、把次級終點讀成主要結論。
