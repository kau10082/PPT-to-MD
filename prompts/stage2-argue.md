# ppt-to-md 第二階段：講者論點還原（有界保真）

> 本提示詞的輸入是第一階段 `extract.py` 產出的 markdown，
> 已含表格結構、且備註已分成「本頁專屬口述」與「制式引註」兩類。
> 任務不是再轉檔，而是「忠實還原講者的原始論點」。

```
# 角色與輸入
你要處理的，是一份「已由程式機械抽取」的學術簡報 markdown。
它已具備：投影片本文、還原成表格的比較表、以及被標記為兩類的備註——
「講者備註（本頁專屬口述論點）」與「〔跨頁重複的制式引註〕」。
你的任務不是再轉檔，而是「忠實還原講者的原始論點」。
最高原則：寧可保留破碎與不確定，也不要為了通順而改寫或補橋。

# 備註分級（最重要）
- 只有標為「本頁專屬口述論點」的備註，才可當作講者論點的依據。
- 標為「制式引註」的備註（跨頁重複的模板殘留）一律「不得」當論點依據，
  也不得併入論點清單；如需保留，另置於「參考資料」區並註明非講者口述。
- 若某頁投影片本文與其口述備註衝突，以口述為準，並明白標出兩者差異。

# 表格與結構陷阱
- 表格中的空白儲存格代表原檔的「合併儲存格」，不是缺值。
  不得自行填補、不得推論它應該是什麼。
- 不得主動製造講者沒有明說的「跨欄比較」結論
  （例如「A 試驗重度病人比 B 多」），除非該比較本來就寫在原文或口述裡。
- 線性排列的順序來自版面座標，「不等於」講者口說順序；
  遇到原本可能是並列／對照的視覺區塊（如四格事件圖），
  標〔原為並列結構，順序不確定〕，不要當成有先後的論證鏈。

# 贊助立場處理
- 這類多為廠商贊助的產品簡報，本身帶行銷立場。
- 檔案內任何免責或方法學警語（例如「未進行 head-to-head 比較，
  不宜直接比較或下結論」）一律逐字保留，並在論點清單開頭「先」列出，
  作為閱讀全篇的前提，不得淹沒在末尾。
- 對「本品優於對照」這類推廣式主張，保留原文，但於論點清單中
  標註其證據等級（RCT／真實世界回顧／單一研究／機轉推論），不得概化為定論。

# 三層分離
1. 原文層：主張、數據、引用、限制，逐字或近逐字保留講者用語；
   關鍵論證句以引言呈現，不改寫、不合併、不重排。
2. 結構層：僅做標題階層與分段，此層可動。
3. 延伸層：任何你補的連接邏輯／背景／推論，一律以 🔸〔延伸推論〕標記，
   且可獨立刪除。預設不產生延伸層，除非某處非補不可。

# 保真規則
- 不得把不確定語氣升級為肯定：「可能／傾向／尚未證實／在此小樣本中」
  等 hedge 全數保留。
- 代理終點、次要指標、單一研究結論，維持原始限定，不得概化。
- 數字、單位、分母、p 值、CI、引用格式一律照抄，不四捨五入、不重排。

# 輸出格式
- 每頁一個區塊，以 --- 分隔。
- 保留原檔的表格與備註分級標記。
- 結尾附「講者論點清單」：
  0) 前提警語（免責／方法學限制）先列。
  1) 逐條列出講者核心主張，每條標註：依據頁碼 ＋ 證據等級 ＋
     依據來源（投影片本文／本頁專屬口述）。
  2) 明確排除制式引註來源的內容。

# 輸出前自我檢查
逐條確認：
- 有沒有任何一句是原檔沒說、我補出來的？未標 🔸 就刪或標。
- 有沒有把「制式引註」誤當講者論點？
- 有沒有替合併儲存格填值、或製造原文沒有的跨欄比較？
- 免責警語是否保留並前置？
```

## 使用後的人工核對（human holdout，不可省）

第二階段能擋掉多數陷阱，但以下三處必須人工回看原檔確認，模型看不見自己的盲點：

1. **合併儲存格留白處** — 確認每個空白格屬於哪一組（表格最左欄尤其常見）。
2. **並列/對照視覺區塊** — 被攤平後的順序是否被誤讀成論證先後。
3. **贊助立場的份量** — 免責警語是否有被適當突顯，推廣式主張的證據等級是否被誠實標註。
